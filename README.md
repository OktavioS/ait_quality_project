# IoT Система моніторингу якості повітря та мікроклімату

Курсовий проєкт з дисципліни "Мікроконтролери".

## Структура проєкту:
* `/firmware_esp32` — прошивка для мікроконтролера ESP32-C6 (C++, Arduino IDE, WiFiManager).
* `/backend` — серверна частина (Python, Flask, SQLite), розгорнута на PythonAnywhere.
* `index.html` — клієнтський веб-інтерфейс (JS, Chart.js, HTML/CSS), розгорнутий на GitHub Pages.
